# nba-mvp-analyzer
NBA MVP Profile Analyzer - Interactive Web Application.  Проект для хакатона AQX Sports Analytics Data Bowl 4.0.  Сравнивает профили игроков NBA с эталонным профилем MVP (Radar Chart) и находит недооцененных игроков с помощью косинусного сходства (Cosine Similarity).  Стек: Python, Streamlit, Pandas, Plotly, Scikit-learn.
