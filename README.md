# 🏀 NBA MVP Profile Analyzer

Интерактивное веб-приложение для анализа того, что на самом деле отличает
MVP от элитных игроков, и поиска «скрытых MVP» — игроков с профилем метрик,
близким к MVP, но не получивших награду.

## Проблема
Голосование за MVP часто награждает победы команды и медийность, а не
индивидуальную эффективность. Мы показываем, какие метрики реально
формируют профиль MVP, и кто из игроков недооценён.

## Что делает приложение
- Вкладка «Сравнить с MVP» — radar chart метрик игрока против среднего
  профиля MVP (PTS, AST, REB, PER, WS, BPM, VORP, USG%, TS%).
- Вкладка «Найти скрытого MVP» — косинусное сходство профиля игрока
  со средним профилем MVP и список игроков, похожих на MVP, но не в топе
  по комплексному скору.

## Данные
data/nba_stats.csv — статистика игроков (120 игроков, 30 команд, 20 метрик).
Данные сгенерированы на основе реалистичных распределений NBA
(generate_data.py), без внешних зависимостей и API.
